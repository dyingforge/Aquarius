# 06: 预览确认并提交记忆修正

**What to build:** 当回答不符合预期时，用户可以用自然语言指出需要修正的记忆；Aquarius 会定位影响条目、展示修改差异和语义类型，并且只有在用户确认后才更新 Git HEAD 和后续回答。

**Blocked by:** 04: 用当前记忆回答并给出引用

**Status:** ready-for-agent

- [ ] 修正预览能区分错误纠正、随时间变化、忘记和一般内容修改，并显示受影响 memory ID。
- [ ] 预览包含修改前后差异、来源影响和预计生成的当前有效状态，但不会立即修改 Git 或 SQLite 投影。
- [ ] 用户取消或预览过期时，memory repository 不发生变化。
- [ ] 用户确认时必须携带预览所基于的 expected HEAD；HEAD 已变化时拒绝提交并要求重新生成预览。
- [ ] 确认后创建可审计的 Git commit，更新 summary 和 FTS，后续查询立即使用新状态。
- [ ] 时间变化会关闭旧条目的有效期而不是伪装成历史错误；错误纠正会记录替换关系。
- [ ] `forget` 明确提示它只移出当前视图，不承诺擦除 Git 历史。
